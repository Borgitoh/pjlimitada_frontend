# Como Acessar o Sistema de Afiliados

## 1️⃣ Fazer Login

### Para Admin (Ver Todos os Afiliados)
- **Email**: `admin@pjlimitada.com`
- **Senha**: `senha123` (qualquer senha com 6+ caracteres funciona)

### Para Usuário Normal (Ver Seus Próprios Afiliados)
- **Email**: `joao@empresa.com` ou `maria@empresa.com`
- **Senha**: `senha123`

---

## 2️⃣ Acessar o Sistema de Afiliados

### Se você é **ADMIN**:
1. Depois de fazer login, clique no menu esquerdo em **"Utilizadores"**
2. Na tabela que aparecer, você verá um botão **"Afiliados"** (ícone de pessoas) em cada usuário
3. Clique no botão **"Afiliados"** de um usuário
4. Um painel lateral abrirá com:
   - ✅ Dados de afiliação daquele usuário
   - ✅ Afiliados diretos
   - ✅ Comissões geradas
   - ✅ **Opção para configurar comissões** (taxas e bónus)

### Se você é **USUÁRIO NORMAL**:
1. Depois de fazer login como João ou Maria
2. Acesse a rota `/my-affiliate` na barra de endereços
3. Você verá:
   - ✅ Seu referidor (quem o indicou)
   - ✅ Link de convite para compartilhar
   - ✅ Seus afiliados diretos
   - ✅ Comissões que já ganhou
